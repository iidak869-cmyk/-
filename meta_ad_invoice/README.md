# Meta広告 請求書集計（テスト環境）

指定フォルダ内のMeta広告請求書PDFを読み取り、PDFごとにExcelファイルを作成したうえで、
共有ドライブ上の集計用Excel（`成功`シート）へ請求情報（キャンペーン名・日時・消化金額・
参照番号・クレカ番号・アカウント名）を転記するローカル実行用Pythonスクリプトです。
必要項目を正しく取得できなかったファイルは「白紙」フォルダへ自動的に振り分けられます。

## セットアップ

Windows端末（`C:\` および `G:\共有ドライブ` にアクセスできる端末）で実行してください。

```bat
pip install -r requirements.txt
```

## 実行方法

対象月の集計用Excel（`<billing-month>月請求分.xlsx`）がまだ存在しない場合は、
`--template` にひな形ファイル（`キャンペーン名/日時/消化金額/参照番号/クレカ番号/アカウント名`
の6列ヘッダーを持つ`成功`シートを含むExcel）を指定してください。初回はそのひな形が
コピーされて対象月のファイルが新規作成されます。2回目以降（同じ月に再実行する場合）は
`--template` を省略でき、既存ファイルに追記されます。

```bat
python aggregate_invoices.py ^
    --source "C:\Users\iida869\Downloads\202605_CS運用・TRANSCEND＆ValueCreationRoom＆株式会社Growth canvas＆Hackeer＆ピラティス" ^
    --temp-dir "C:\Users\iida869\Downloads\_一時保存" ^
    --billing-month 5 ^
    --template "G:\共有ドライブ\RPA運用-技術課連携\〇月請求分_ひな形.xlsx"
```

| オプション | 必須 | 説明 |
| --- | --- | --- |
| `--source` | ○ | PDF請求書が入っているフォルダ |
| `--temp-dir` | ○ | PDFから作成したExcelファイルの一時保存先 |
| `--billing-month` | ○ | 対象請求月（例: `5` → `5月請求分.xlsx`） |
| `--template` | 初回のみ | 対象月の集計用Excelが未作成の場合にコピー元とするひな形ファイル |
| `--rpa-dir` | - | 集計用Excel・白紙フォルダの親フォルダ（既定値: `G:\共有ドライブ\RPA運用-技術課連携`） |
| `--blank-dir` | - | 不備ファイルの移動先（既定値: `<rpa-dir>\白紙`） |
| `--debug` | - | PDFから抽出した生テキストを一時保存先に `.debug.txt` として書き出す |

## 処理の流れ

1. `--source` フォルダ内のPDFを1件ずつ読み取り、PDFごとにExcelファイル（`<PDFファイル名>.xlsx`）を
   `--temp-dir` に作成する
2. 対象月の集計用Excel（`--rpa-dir\<billing-month>月請求分.xlsx`）が無ければ `--template` を
   コピーして作成し、一時保存フォルダのExcelファイルを1件ずつ確認して`成功`シートへ
   請求情報を転記する（同じ参照番号・キャンペーン名・金額の組み合わせが既に転記済みの場合は
   スキップするので、再実行しても重複しない）
3. 6項目（キャンペーン名・日時・消化金額・参照番号・クレカ番号・アカウント名）の
   いずれかが取得できなかったExcelファイルは、転記せず `--blank-dir`（既定: 白紙フォルダ）へ移動する

## 項目の取得元（実際のMeta広告請求書PDF3件で検証済み）

- **キャンペーン名・消化金額**：PDF本文の明細行（`<キャンペーン名>` の次の行に `¥<金額>` が
  単独で並ぶ箇所）から、キャンペーンの数だけ取得します。1PDFに複数キャンペーンが含まれる場合は
  行を分けて転記します（検証した3件は5〜6キャンペーン/PDFでした）。
- **日時**：PDF内の「請求書/支払日」に記載された支払日時（1請求書につき1つ）を使用します。
  ※各キャンペーンの広告掲載期間ではなく、支払日時を採用する仕様で確定しています。
  集計用Excelの書式に合わせてExcel上は日付型で保存されます。
- **参照番号・クレカ番号**：PDF内の「参照番号:」「支払い方法」欄からそれぞれ取得します。
- **消化金額**：集計用Excelの書式に合わせて、Excel上は「¥」記号やカンマを除いた数値型で保存されます。
- **アカウント名**：PDF本文（末尾が「…」で省略されることがある）ではなく、
  **PDFが入っているフォルダ名**（例: `202605_CS運用・TRANSCEND＆...`）から、
  先頭の `YYYYMM_` を除いた部分を使用する仕様で確定しています。

## 注意事項・既知の制約

- 上記の抽出ロジックは、実際にダウンロードされたMeta広告請求書PDF3件（同一アカウント）で
  検証済みです。ただし請求方式や時期、他のアカウントでPDFのレイアウトが変わる可能性はあるため、
  他のPDFでも転記結果を必ず目視確認してください。ズレがあれば `aggregate_invoices.py` の
  `REFERENCE_PATTERN` / `CARD_PATTERN` / `PAYMENT_DATETIME_*` / `AMOUNT_ONLY_LINE` を調整します。
- 検証した3件はいずれも「必要項目を正しく取得できなかった」パターン（白紙行き）の実例が
  無かったため、白紙振り分けの動作は合成テストデータでのみ確認済みです。実運用でそのような
  PDFに遭遇した場合は、挙動を確認のうえ必要に応じて調整してください。
- パターン調整時は `--debug` を付けて実行すると、各PDFから抽出した生テキストが
  一時保存フォルダに `.debug.txt` として出力されるので、実際の項目名の表記を確認できます。
- 本スクリプトはこのリポジトリの実行環境（クラウド上のLinuxコンテナ）ではなく、
  `C:\` や `G:\共有ドライブ` にアクセスできるユーザー端末での実行を前提としています。
