# 社内AI利用状況の可視化ツール（Googleフォーム → スプレッドシート → ダッシュボード）

社内メンバーが「どのAIツールを・どんな業務に・どれくらい使っているか」を集めて可視化する
Google Apps Script (GAS) です。**追加費用はかかりません**（Googleフォームとスプレッドシートのみ）。

- Googleフォームで各メンバーが利用状況を申告
- 回答はスプレッドシートに自動で溜まる
- GASがツール別・用途別・メンバー別・週次推移に集計し、グラフ付きダッシュボードを自動生成
- 「うまくいった使い方」「困っていること」を`共有ナレッジ`シートに一覧化

## なぜ自己申告方式か

ChatGPT / Claude / Gemini の利用実績をAPIで直接取得するには、各サービスの
**管理者向けAPI（有料のTeam / Enterpriseプラン）** が必要で、しかもサービスごとに個別対応になります。
自己申告方式なら費用ゼロで今日から始められ、**社内で実際に使われている全ツールを横断して**
把握できます（どのツールを契約すべきかの判断材料にもなります）。

将来的に管理者APIが使えるようになった場合は、`回答_生データ`シートと同じ形式でデータを
書き込めば、集計・ダッシュボード側はそのまま流用できます。

## セットアップ手順

1. https://script.google.com で新しいプロジェクトを作成する（既存のアンケート同期スクリプトとは**別プロジェクト**にしてください）
2. `gas-ai-usage/Code.gs` の内容をコピーして、プロジェクトのコードとして貼り付ける
3. エディタ上部の関数選択で `setup` を選び、実行する
   - 初回実行時はGoogleアカウントへの権限承認が必要です
   - スプレッドシート「AI利用状況ダッシュボード」とフォーム「AI利用状況アンケート」が新規作成されます
   - フォーム送信時＋毎朝8時の自動集計トリガーが登録され、初回の集計が実行されます
4. 実行ログ（表示 > 実行数）に出力される2つのURLを開く
   - **ダッシュボードのURL**: 集計結果を確認する用（社内共有は任意）
   - **回答フォームのURL**: 社内メンバーに配布する用
5. スプレッドシートの`設定`シートにメンバー名と部署を入力する
6. エディタで `applySettingsToForm` を実行し、フォームの「氏名」「部署」の選択肢に反映する

以降はフォームに回答が入るたび、および毎朝8時に自動で集計され直します。
手動で集計し直したいときは `refreshDashboard` を実行してください。

## 生成されるシート

| シート | 内容 |
| --- | --- |
| `ダッシュボード` | KPI（申告件数・申告カバー率・合計利用時間・合計削減時間・平均使いこなし度・最多ツール／用途・未申告メンバー）と4つのグラフ |
| `集計_ツール別` | AIツールごとの申告件数・利用人数・利用時間 |
| `集計_用途別` | 用途ごとの申告件数・利用人数・削減時間 |
| `集計_メンバー別` | メンバーごとの申告件数・利用時間・削減時間・使いこなし度・使用ツール・主な用途・最終申告日 |
| `集計_週次推移` | 週（月曜始まり）ごとの申告件数・申告人数・利用時間・削減時間 |
| `共有ナレッジ` | 「うまくいった使い方」「困っていること」の自由記述の一覧（新しい順） |
| `設定` | 集計対象期間（日）、メンバー一覧、部署一覧（**ここを編集して運用します**） |
| `回答_生データ` | フォームの回答そのまま（フォーム連携シートを自動リネーム。手で編集しないでください） |

ダッシュボードのグラフは4種類です。

- ツール別の利用状況（申告件数・利用人数）
- 用途別の申告件数（どんな業務に使われているか）
- 週次推移（申告人数・利用時間・削減時間）
- メンバー別の利用時間・削減時間

## 集計のしくみ

- 集計対象は`設定`シートの「集計対象期間（日）」で指定した直近N日（初期値90日）。
  各回答の「対象日」で判定します（未記入の場合は回答日時を使用）。
- 利用時間・削減時間は選択肢を代表値に換算して合計します
  （例: `15〜30分` → 0.375時間、`1〜2時間` → 1.5時間、`4時間以上` → 5時間）。
  あくまで**体感値の目安**であり、実測値ではありません。
- 「使ったAIツール」「主な用途」は複数選択なので、1回答が複数のツール／用途に加算されます。
  そのため各シートの申告件数の合計は回答数より多くなります。
- 「申告カバー率」は`設定`シートの登録メンバーのうち、期間内に申告した人の割合です。
  `設定`シートに載っていない人が回答した場合は「`設定`シートに未登録の回答者」に表示されるので、
  そこに名前が出たら`設定`シートに追加してください。

## 質問項目を変えたいとき

`Code.gs` 先頭の以下の定数を編集します。

- `TOOL_CHOICES` : AIツールの選択肢
- `PURPOSE_CHOICES` : 用途の選択肢
- `USAGE_TIME_OPTIONS` / `SAVED_TIME_OPTIONS` : 時間の選択肢と、集計で使う代表値（`hours`）
- `Q` : 質問文（**回答シートの見出しと一致している必要があります**。変更する場合は既存の
  `回答_生データ`シートの見出しも同じ文言に直してください）

`TOOL_CHOICES` / `PURPOSE_CHOICES` を変更した場合、既存フォームの選択肢は自動更新されないため、
フォーム側で選択肢を直接編集するか、フォームを作り直してください
（作り直す場合はスクリプトプロパティ `AI_USAGE_FORM_ID` を削除して `setup` を再実行します）。

## 集計スケジュールの変更

`Code.gs` の `registerTriggers()` 内、
`ScriptApp.newTrigger('refreshDashboard').timeBased().everyDays(1).atHour(8).create();`
の時刻・頻度を変更し、`setup()` を再実行するとトリガーが更新されます。

## スクリプトプロパティ

`setup()` が自動で設定します。手動で設定する必要はありません。

| キー | 内容 |
| --- | --- |
| `AI_USAGE_SPREADSHEET_ID` | ダッシュボード用スプレッドシートのID |
| `AI_USAGE_FORM_ID` | 回答フォームのID |

既存のスプレッドシート／フォームを使いたい場合は、これらのプロパティにIDを設定してから
`setup()` を実行してください。
