# 改修タスク デイリーTODOルーチン

Notion「改修かも内容」ページの未完了タスクを、平日朝9時に自動でTODO化して実行するルーチンの仕様メモ。

## スケジュール

- **実行タイミング**: 平日（月〜金）朝 9:02 JST（cron: `2 0 * * 1-5` UTC）
- **実行方式**: Claude Code Remote のRoutine（トリガーID: `trig_01HcRjSB73FUwaYqTJgzcdHQ`）が毎回新しいセッションを起動
- **通知**: 実行完了時にプッシュ通知・メール通知あり

## 参照するNotionリソース

| リソース | ID |
|---|---|
| 改修かも内容ページ（要件定義の置き場） | `39582531-94ba-8066-b245-d13936b1aaec` |
| プロジェクトDB（タスク一覧・ステータス管理） | `collection://95582531-94ba-820c-9f81-0701e25bc574` |
| デイリーTODO DB（日次プランの出力先） | `collection://e8454d0b-2857-4dad-87a7-723f42ce164f` |

## 毎朝の処理フロー

1. 「改修かも内容」ページを読み、各タスクの最新の要件定義を取得する（要件定義はページ内で随時更新される前提）
2. プロジェクトDBからステータスが「完了」以外のタスクを抽出する（未完了がなければ何もせず終了）
3. 優先度・期日をもとに当日取り組むタスクを選定する
4. 9:00〜18:00（昼休憩1時間・実働8時間）の時間帯つきチェックリストとしてTODOを作成し、デイリーTODO DBに「YYYY-MM-DD デイリーTODO」ページを作成する（同日ページが既にあれば更新）
5. 前営業日の「持ち越し・メモ」を確認し、未完了項目を当日プランに引き継ぐ
6. 着手したプロジェクトのステータスを「進行中」に更新する（完全に終わったら「完了」）
7. セッション内で実行可能な作業（要件整理・設計・GAS等の実装案・手順書作成）は実際に実行し、成果物をNotionに追記、完了項目にチェックを入れる
8. 要件不足で進められない項目は「持ち越し・メモ」に質問形式で記録する

## 制約

- 外部システム（スプレッドシート、メールディーラー、ジョブカン、Googleカレンダー等）への実接続が必要な作業は、接続手段がない場合は実装コード案・設定手順書の作成までにとどめ、人間が実施すべき手順を明記する

## ルーチンの管理

セッションから `list_triggers` / `update_trigger` / `delete_trigger`（Claude Code Remote MCP）で確認・時刻変更・停止ができる。
