# ほうこっくん 契約数更新（NG含む）自動化

「ほうこっくん」の営業報告（契約・NGを含む）を取得し、営業報告データベースExcelへ
重複なく追記、追加分だけをテスト用Googleスプレッドシートへ転記する自動化プログラムです。

開発は段階を分けて進めます。現在は **第1段階** です。

## 第1段階でやること
- Windows PCにPythonを準備する
- このプロジェクト用の仮想環境を作り、必要なライブラリをインストールする
- `.env` を作成し、Excelファイルの場所などを設定する
- 実際の営業報告データベースExcelを正しく読み込めるか確認する
- （Googleスプレッドシートへの転記はまだ無効のままでOK）

以下、WindPCでの操作を1つずつ説明します。

---

## 手順1: Pythonがインストールされているか確認する

1. キーボードの `Windowsキー` を押しながら `R` を押す（「ファイル名を指定して実行」が開きます）
2. `cmd` と入力して `OK` を押す（黒い画面＝コマンドプロンプトが開きます）
3. 次のコマンドを入力して `Enter` を押す
   ```
   python --version
   ```
4. `Python 3.11.x` のようにバージョンが表示されればインストール済みです。手順2へ進んでください。
5. 「'python' は、内部コマンドまたは外部コマンド...として認識されていません」と表示された場合は、
   Pythonがインストールされていません。以下の手順でインストールしてください。
   1. ブラウザで https://www.python.org/downloads/ を開く
   2. 「Download Python 3.x.x」という黄色いボタンをクリックしてインストーラーをダウンロードする
   3. ダウンロードしたファイル（`python-3.x.x-amd64.exe` など）をダブルクリックして実行する
   4. インストーラー最初の画面で、下の方にある **「Add python.exe to PATH」に必ずチェックを入れる**
   5. 「Install Now」をクリックしてインストールする
   6. インストール完了後、一度コマンドプロンプトを閉じて開き直し、手順1の3をもう一度実行して確認する

## 手順2: プロジェクトフォルダを準備する

このフォルダ（`hokokkun_sales_report_automation`）一式を、Windows PCの分かりやすい場所
（例: `C:\Users\あなたの名前\Documents\hokokkun_sales_report_automation`）にコピーしてください。

コマンドプロンプトで、そのフォルダへ移動します（パスはご自身の環境に合わせてください）。
```
cd C:\Users\あなたの名前\Documents\hokokkun_sales_report_automation
```

## 手順3: 仮想環境を作成し、必要なライブラリをインストールする

1. コマンドプロンプトで次のコマンドを1行ずつ入力し、都度 `Enter` を押してください。
   ```
   python -m venv venv
   ```
2. 続けて仮想環境を有効化します。
   ```
   venv\Scripts\activate
   ```
   コマンドプロンプトの行頭に `(venv)` と表示されれば成功です。
   これ以降、このプロジェクトの作業をするときは、必ず先に `venv\Scripts\activate` を実行してください。
3. 必要なライブラリをインストールします。
   ```
   pip install -r requirements.txt
   ```
   少し時間がかかります。エラーが出た場合は、そのエラーメッセージをそのまま教えてください。
4. Playwright（ブラウザ自動操作ツール）が使うブラウザ本体をインストールします。
   ```
   playwright install chromium
   ```

## 手順4: `.env` ファイルを作成する

1. エクスプローラーでプロジェクトフォルダを開く
2. `.env.example` というファイルをコピーして、同じフォルダに貼り付ける
3. 貼り付けたファイルの名前を `.env` に変更する（拡張子部分だけでなく、ファイル名全体を `.env` にしてください）
4. `.env` を右クリック→「プログラムから開く」→「メモ帳」で開く
5. 今の第1段階では、以下の2つが合っていることだけ確認してください（すでに設定済みのはずです）。
   ```
   EXCEL_FILE_PATH=G:\共有ドライブ\RPA運用-技術課連携\RPA検証用_テストデータ\契約数更新NG含む\営業報告データベース.xlsx
   EXCEL_SHEET_NAME=データベース
   ```
   実際のファイルパスと違う場合は、ここを実際のパスに書き換えて保存してください。
   `HOKOKKUN_URL` などのログイン情報は、まだ空欄のままで問題ありません（第2段階で設定します）。

## 手順5: Excelを読み込めるか確認する

1. 対象のExcelファイル（`営業報告データベース.xlsx`）が **開かれていない**（閉じている）ことを確認してください。
2. コマンドプロンプトで、次のコマンドを入力して `Enter` を押してください。
   ```
   python scripts\stage1_check_excel.py
   ```
3. 次のような内容が表示されれば成功です。
   ```
   [OK] Excelを読み込めました。シート一覧: [...]
   [OK] 見出し行(1行目)は想定通りです。
   最終データ行: ...行目（データ件数: ...件）
   ```
4. 表示された内容を、そのままコピーして私（Claude）へ教えてください。特に以下を確認したいです。
   - 「見出し行が想定と異なります」という注意が出ていないか
   - データ件数が何件と表示されるか
   - 「納品物件列(S〜Z列)のサンプル」に何が表示されるか（実データがある場合）
   - もしデータが0件で「[確認事項]」というメッセージが出た場合は、その旨も教えてください
     → その場合、納品物件（ネット1/ネット2/HP/動画サイト/LP/LINE/動画CR/Cyteki）の実際の入力例が
       分かる行を、別途スクリーンショットまたはテキストで見せていただけると助かります。

エラーが表示された場合は、表示された内容をそのまま貼り付けて教えてください。内容を見て次の対応を案内します。

## フォルダ構成（現時点）

```
hokokkun_sales_report_automation/
  .env.example        # 設定ファイルのひな形（.envを作る元）
  .gitignore
  requirements.txt     # 必要なPythonライブラリ一覧
  README.md            # このファイル
  src/
    config.py          # .env の読み込み
    excel_io.py         # Excelの読み込み・追記・保存の処理
    normalize.py        # 会社名の重複判定用の正規化処理
  scripts/
    stage1_check_excel.py  # 第1段階の確認スクリプト
  logs/                 # 実行ログの保存先（今後使用）
  temp/                 # 一時ファイルの保存先（今後使用）
```

## 今後の予定

- 第2段階: Playwrightのcodegenを使って、ほうこっくんの画面操作を記録します（ログイン、一覧表示、詳細表示など）。
- 第3段階: 実際にほうこっくんからデータを取得し、Excelへの追記・保存・ログ出力を行います。
- 第4段階: テスト用Googleスプレッドシートへの転記を有効化します。
- 第5段階: 通しテストを行い、Windowsタスクスケジューラへ登録します。

各段階が終わったら、結果を確認してから次に進みます。
