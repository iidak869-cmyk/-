# 契約数更新(NG含む)自動化 — ほうこっくん → Excel → Googleスプレッドシート

ほうこっくんに登録されている**前日・当日**の営業報告(契約案件・NG案件を含むすべて)を取得し、
営業報告データベースExcelへ**会社名の重複を除いて**追記します。
追記後、**今回新規追加したデータのみ**を指定のGoogleスプレッドシートへ転記します。

Windowsのタスクスケジューラで**毎日9:30**に自動実行します。

## 処理の流れ

1. ほうこっくんへログイン
2. 営業報告データベースExcelを読み込み
3. 「前日」を選択
4. 項目一覧から「営業」を選択し、営業報告一覧を取得
5. 一覧を1件ずつ開いて必要項目を抽出
6. Excel内に同じ会社名が登録済みか確認(重複判定は**会社名のみ**)
7. 未登録の会社のみExcelへ追記
8. 「次日」で当日に切り替えて同じ処理
9. Excelを上書き保存
10. 今回新規追加したデータのみスプレッドシートへ転記

### 抽出項目

契約日 / 商談時間 / 営業方法 / 会社名 / 結果 / NG理由① / 会社所在地 / 代表者名 / 種類 /
営業担当 / 同行 / アポ担当 / 業種 / 契約形態 / 金額 / 納品物件 / クレカ所持 / 初期回収

### NG案件の扱い

- 結果がNGの場合も転記対象です。
- ほうこっくん上のNG理由は1項目のみのため、取得内容を**「NG理由①」**へ転記します。
- **「NG理由②」は使用せず、転記対象から除外**します(Excelに列があってもそのまま残ります)。
- 契約形態・金額・納品物件など、NG案件で情報が無い項目は**空欄**で登録します。

## セットアップ手順(Windows)

### 1. Python と Google Chrome のインストール

- [Python 3.10以上](https://www.python.org/downloads/windows/) をインストール
  (インストーラーで「Add python.exe to PATH」にチェック)
- Google Chrome をインストール(Seleniumが自動でドライバを取得します)

### 2. ファイルの配置とライブラリのインストール

この `sales_report_sync` フォルダを実行するPCの任意の場所(例: `C:\tools\sales_report_sync`)へ置き、
コマンドプロンプトで:

```bat
cd C:\tools\sales_report_sync
py -3 -m pip install -r requirements.txt
```

### 3. Googleサービスアカウントの作成(スプレッドシート転記用)

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成
2. 「APIとサービス」で **Google Sheets API** と **Google Drive API** を有効化
3. 「認証情報」→「サービスアカウント」を作成し、**JSONキー**をダウンロード
4. JSONキー内の `client_email` のメールアドレスに対して、転記先スプレッドシートを**編集者**として共有

### 4. config.ini の作成

`config.example.ini` を `config.ini` という名前でコピーし、以下を設定:

- `[houkokkun]` … ほうこっくんのURL・ログインID・パスワード
- `[excel]` … 営業報告データベースExcelのフルパス
- `[google_sheets]` … スプレッドシートID・サービスアカウントJSONのパス

### 5. 動作確認

`config.ini` の `headless = false` にして画面を見ながら1回実行:

```bat
py -3 main.py
```

ログイン→営業一覧→詳細の遷移が正しく動くことを確認したら `headless = true` に戻します。
うまく遷移しない場合は下の「セレクタの調整」を参照してください。

### 6. タスクスケジューラへ登録(毎日9:30)

管理者権限のコマンドプロンプトで `register_task.bat` を実行するか、手動で:

```bat
schtasks /Create /TN "契約数更新_営業報告同期" /TR "C:\tools\sales_report_sync\run_sync.bat" /SC DAILY /ST 09:30
```

> **注意**: 実行時は対象Excelが**閉じている**状態にしてください。
> 開いたままだと保存できず、エラーとしてログに記録されます(スプレッドシート転記も行いません)。

## セレクタの調整

ほうこっくんの画面HTML構造は環境により異なるため、初回動作確認で
「〜が見つかりません」というエラーが出た場合は `houkokkun.py` 冒頭の `SELECTORS` を
実際の画面(F12の開発者ツールで確認)に合わせて修正してください。

- `login_id_names` / `login_pw_names` … ログイン入力欄の `name` 属性
- `sales_menu_xpath` … 項目一覧の「営業」リンク
- `prev_day_xpath` / `next_day_xpath` … 「前日」「次日」ボタン
- `detail_link_xpath` … 一覧から詳細画面へのリンク

詳細画面のラベル名がExcelのヘッダーと異なる場合は `fields.py` の `LABEL_ALIASES` に
読み替えを追加してください(例: `"NG理由": "NG理由①"`)。

## エラー対策(実装済み)

| 事象 | 動作 |
| --- | --- |
| 詳細画面に「不正なアクセスです。」と表示 | 同じ日の営業一覧を再表示して**1回再試行**。それでも失敗ならスキップしてログに記録 |
| 一部の項目が取得できない | **空欄**として処理を継続 |
| 1件の取得失敗 | 全体を停止せず、失敗内容をログに残して次の件へ |
| Excelが開かれていて保存できない | エラーとしてログに記録(スプレッドシート転記は中止) |
| スプレッドシート転記の失敗 | Excel追記は完了済みのままエラーをログに記録 |

## ログ

実行ごとに `logs\sync_YYYYMMDD_HHMMSS.log` が作成され、
**実行結果・追加件数・重複スキップ件数・取得失敗件数**が末尾に記録されます。

```
実行結果: 正常終了 / 追加 5 件 / 重複スキップ 3 件 / 取得失敗 0 件
```

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `main.py` | メイン処理(手順1〜10の制御・ログ出力) |
| `houkokkun.py` | ほうこっくんへのログイン・画面遷移・詳細抽出(Selenium) |
| `excel_db.py` | Excelの読み込み・会社名重複チェック・追記・上書き保存 |
| `sheets_transfer.py` | 新規追加分のみスプレッドシートへ転記 |
| `fields.py` | 抽出項目とラベル読み替えの定義 |
| `run_sync.bat` | タスクスケジューラから起動する実行バッチ |
| `register_task.bat` | 毎日9:30のタスクを登録するバッチ |
| `config.example.ini` | 設定ファイルのひな形(`config.ini` にコピーして使用) |
